# v0.2 Batch C

光通信・ネットワーク・電線を中心に10社追加し、40社から50社へ拡張する。

追加企業: Coherent, Lumentum, Ciena, Cisco, Credo, Furukawa Electric, Sumitomo Electric, Corning, Amphenol, TE Connectivity.

方針:
- 公式IR入口をSource Registryへ登録する。
- 利用条件未審査Sourceはmanual-reference-onlyとする。
- 財務値は監査前なので未収録のままにする。
- 主観スコアは強制しない。
- 光トランシーバー、コヒーレント光、AEC、高速コネクタ等を別リンクとして扱う。
