# AI Infrastructure Atlas Design System v0.4

## 目的

外観を「AI SaaS」ではなく「産業調査資料 × 金融データベース × 技術図面」に固定する。

## 色

- page: `#F6F6F3`
- surface: `#FFFFFF`
- text: `#17191C`
- muted: `#59616A`
- border: `#D9DDE1`
- link: `#0057B8`

`#59616A` は白背景・page背景の双方でWCAG AAの通常文字コントラストを満たす。赤・橙・緑は状態や警告など意味がある場合だけ使う。

## 文字

本文は16px以上。日本語は Hiragino Sans / Yu Gothic UI / Yu Gothic / Noto Sans JP を優先する。ティッカー、工程番号、日付などだけmonospaceを使う。

## リンク

クリック可能なテキストは青。本文・タグ・出典リンクは原則underlineを使う。装飾目的だけの青文字は作らない。

## 角丸・影

- 通常要素: 0〜2px
- 入力・ボタン: 2px
- shadow: 原則なし
- glassmorphism / backdrop blur: 使用しない
- gradient背景: 使用しない

## 情報構造

同種データはカードではなく表・固定行・定義リストを使う。カードは異質な情報を一つにまとめる必要がある場合のみ検討する。

### トップ

小型導入 → 検索 → 6段バリューチェーン → 調査対象表。

### 企業一覧

固定列テーブル。検索、フィルタ、ソートを維持する。企業名列は横スクロール時も固定する。

### 企業詳細

概要 → バリューチェーン上の位置 → 主力製品 → 競争優位 → 主要拠点 → 財務 → 業種固有KPI → 競合 → リスク → 出典。

分析・編集情報と一次資料由来の客観データを分類表示する。数値の出典・基準日・期間・定義は正式な表列として扱い、小さな脚注だけにしない。

## Motion

hoverはunderline、背景差、border差まで。scale、fade-up、不要なスクロールアニメーションは禁止。`prefers-reduced-motion` を尊重する。

## レスポンシブ

スマートフォンではナビゲーションとデータ表は横スクロールを許容する。情報列を勝手に削除しない。企業詳細は1カラムへ落とす。
