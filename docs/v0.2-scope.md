# v0.2 Scope — 100社化とセクターマップ

## 位置づけ

v0.1は「20社の静的データを、公開URL上で検索・閲覧できる状態」を完成条件とする。

v0.2では、既存UI・URL・検索・比較・財務表示を壊さず、収録企業を100社規模へ拡張し、工程・技術・地域を横断できるセクターマップを整備する。

比較機能や財務機能は既に先行実装されているが、バージョン番号は機能の初出ではなく、各段階の主目的と完成条件で管理する。

## v0.2 完成条件

- 収録企業: 100社程度
- 主要工程: 計算半導体 / メモリ / ファウンドリ / 製造装置 / 検査・後工程 / 接続・光通信 / データセンター / 電力・冷却 / Physical AI を横断
- 主要技術タグから企業一覧へ一意に遷移可能
- セクター別の企業一覧・競合関係を把握できる
- 日本・米国・台湾・韓国・欧州を中心に主要プレイヤーを収録
- 企業一覧の検索・AND検索・複合フィルターが100社規模でも破綻しない
- 既存企業ページURLを維持
- 新規企業もSource / 基準日 / 定義 / 検証状態の原則を継承
- GitHub Pages上で実公開確認

- 全企業への主観スコア強制付与

これらは後段のマイルストーンへ送る。
