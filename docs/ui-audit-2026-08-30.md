# UI/UX監査 — 2026-08-30

対象: AI Infrastructure Atlas 公開版

## 結論

現行サイトはデータ構造・URL・検索・出典管理の基礎は機能している一方、表示層に旧来のSaaSテンプレート表現が残っている。問題は個別の色ではなく、情報の並べ方とCSSの継承構造にある。

## AIテンプレート感の主因

1. `global.css` に背景グラデーション、`backdrop-filter: blur()`、大きな角丸、shadow、pillタグ、カードグリッドが残っている。後段CSSで上書きしており、設計思想が二重化している。
2. トップページが hero + 数値ブロック + 企業カードというSaaSランディングページ型になっている。
3. 企業一覧がカード中心で、列位置を固定した視線比較ができない。
4. 本文が15px、出典・基準日が10pxで、調査データベースとして重要な証拠情報の視認性が低い。
5. 企業詳細では数値のSource・基準日・定義が小さい注記として表示され、編集された証拠管理の存在感が弱い。
6. 全体マップが角丸の箱を並べる構成で、工程図・技術図面よりカードUIに見える。
7. CSSが `global.css → readability.css → research-note.css` の三層上書きになっているため、旧UIの表現が残存・再発しやすい。
8. リンク色は改善されているが、タグ・企業名・工程と通常本文との視覚的ルールをさらに統一できる。

## 第一段階で変更する範囲

- デザインシステムを単一CSSへ整理
- 背景、文字色、リンク色、境界、focus、motionを再定義
- 本文16px以上、出典12px以上へ引き上げ
- トップのheroを縮小し、技術図面風バリューチェーンを主役にする
- トップの企業カード群を更新・調査対象の表へ変更
- 企業一覧を検索・フィルタ・ソート可能なデータテーブルへ変更
- 企業詳細を調査レポート型へ整理し、出典・基準日・定義を表の正式列として扱う
- 全体マップを直線・罫線主体の工程図型へ変更
- 比較・検索は既存機能を維持し、同じデザインシステムへ統合

## 維持するもの

- 既存URL
- 企業データ
- タグとフィルタの意味
- Pagefind全文検索
- 企業比較
- Source/基準日/定義のデータ構造
- GitHub Pages deployment
- ロゴ権利ゲート
- 拠点Source/Policy管理
