# v0.1 Scope Lock

All scope decisions are subordinate to `docs/constitution.md`.

## Primary user flows

1. **Atlas → Company**: understand where a company sits in the AI infrastructure chain.
2. **Companies → Filter → Company**: narrow the universe by company/layer/country.
3. **Company → Compare**: compare up to four companies on normalized fields.
4. **Search → Company**: search across products, strengths, risks, and AI role.

## Included

- 20-company static research universe
- 8-layer taxonomy
- multi-layer company membership + single primary layer
- company profile template
- provisional sensitivity/structure scores, explicitly separated from objective data
- universal metrics schema with Source/as-of/definition provenance contract
- Source Policy Registry
- static search
- Pages CI/CD skeleton with validation gate

## Explicitly excluded from v0.1

- real-time prices or real-time market-data distribution
- automatic earnings ingestion
- news feed
- portfolio/watchlist sync
- authentication
- server/database
- automatic LLM rewriting of analyst conclusions
- unsourced company-to-company relationship claims
- third-party chart/screenshot republication as a content workflow
- automated retrieval from sources whose usage terms are not reviewed

## Exit criteria for v0.1

- production build succeeds
- 20 company detail routes build
- filters work without server state
- four-company comparison works
- Pagefind indexes the built HTML
- GitHub Pages workflow is present
- all 20 registered Sources have Source Policy records
- non-null objective numeric data cannot validate without Source/as-of/definition
- analysis scores identify assessment source/date/definition
- secret-pattern CI check passes
- every financial metric can represent missing data without ambiguity


## Release / exit criterion

Source completion is not release completion. v0.1 exits only after the built site has been deployed and a real HTTPS URL can be opened in a normal browser. The deployed release must expose the core navigation and interactions (Atlas, company search/filtering, company pages, comparison, and full-text search). See `delivery-requirements.md`.
