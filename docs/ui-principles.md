# UI Principles

AI Infrastructure Atlas の表示・操作設計に関する基準。

1. 本文は白背景・濃い文字を基本とし、薄い灰色は補助情報に限定する。
2. 青色は原則としてクリック可能な要素に使う。操作できない数値やティッカーを装飾目的で青くしない。
3. 日本語で自然に表現できるUI・説明は日本語を優先する。企業正式名、ティッカー、GPU、HBM、EUV、CUDA等の定着した固有名詞・専門語は無理に訳さない。
4. 巨大見出し、過剰な角丸、チップ、カード、グラデーション、装飾アイコンを常用しない。投資調査資料・業界データベースに近い情報密度を優先する。
5. タグ、産業領域、国・地域、拠点都市は探索導線としてリンク化する。
6. 主要製造・研究拠点は都市・地域・役割・一次情報源をセットで管理する。全拠点を網羅していると誤認させない。
7. 企業ロゴはブランド資産の利用条件を確認し、brand-assets registryで displayAllowed=true になったものだけ表示する。公式サイトに掲載されているという理由だけで転載しない。
8. AIによる暫定評価と客観データを視覚的にも分離し、同じ見た目で事実のように扱わない。
