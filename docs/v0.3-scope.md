# v0.3 Scope — 企業比較の本格化

## 目的

100社の企業データから3〜5社を選び、事業・技術・拠点・財務・業種固有KPIを横並びで比較できる調査端末にする。

## 完成条件

- 100社から検索して比較対象を追加できる
- 最大5社をURL付き比較セットとして保持できる
- 主要セクターの比較プリセットを用意する
- 共通財務指標に「比較可 / 条件注意 / 比較不能」を表示する
- 比較不能・注意の理由（期間、算出基準、検証状態、欠損）を明示する
- 数値セルから決算期間・検証状態・一次資料へ辿れる
- 業種固有KPIは同一定義が2社以上に存在しない場合「参照のみ」と明示する
- 主観スコアは客観データと分離し、既定表示では前面に出さない
- 既存100社、企業URL、検索、タグ、GitHub Pages公開を維持する

## 比較ポリシー

### 比較可

2社以上に値があり、同一定義・同一決算期間・同一算出基準で、比較対象値が検証済みである場合。

### 条件注意

同じ指標として参照可能だが、決算期の日付、GAAP/IFRS、会社開示値/Atlas計算、検証状態などに差がある場合。差異の理由を行見出しに表示する。

### 比較不能

2社以上に値がない、四半期と通期が混在する、定義が異なるなど、横並び数値を同列比較すべきでない場合。

## v0.3でやらないこと

- 未収録財務値の推測補完
- リアルタイム株価
- 未審査Sourceの自動取得
- 財務時系列の本格実装（v0.4）
- 主観スコアを客観財務と同列に扱うこと
